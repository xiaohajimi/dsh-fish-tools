# demo

- `whale-idle-game.html` — a single-file idle game (open it in any browser).
  You raise a small whale: work for tokens, feed it, slack off. It ends when the mood
  collapses or you clock out. Ranked S/A/C/F.

  It is here because it is a complete example of the smallest thing that still feels
  alive: one file, no build step, no dependency. Copy it and change the events table
  to make your own.

  Written for the DeepSeek "whale" persona meme; the code itself is generic.
