# 在 8 GB 显存上跑 Gemma-4 E4B QLoRA：环境与脚本说明

> 目标：单卡 8 GB（RTX 5070 Laptop / RTX 4060 Ti 等都适用）把 E4B 微调起来。

---

## 一、依赖

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu124
pip install transformers>=5.0 accelerate peft bitsandbytes datasets
```

实测版本组合（2026-11）：`transformers 5.x` + `peft` + `bitsandbytes 0.4x` + CUDA 12.4。

**注意**：transformers 5.x 移除了 `warmup_ratio`，要用 `warmup_steps`。

---

## 二、显存账本（8 GB 怎么塞进去的）

| 项目 | 占用 |
|---|---|
| E4B 4bit NF4 权重 | ~5 GB |
| LoRA 可训练参数 | ~0.1 GB |
| 激活值（seq 512 + grad checkpointing） | ~2 GB |
| **合计** | **~7.6 GB（贴着 8 GB 跑）** |

**三条必须做的事**：

```python
model.gradient_checkpointing_enable()
model.enable_input_require_grads()
# 跳过 prepare_model_for_kbit_training —— 它的 fp32 上采样要 10.5 GB，8 GB 必爆
```

---

## 三、4bit 之后 LoRA 挂不上的坑（最关键）

bitsandbytes 会把 `nn.Linear` 包成 `ClippableLinear(linear=Linear4bit)`，
**PEFT 的正则不匹配 `.*\.linear$`**，结果是 `target_modules` 静默为空、训练“成功”但什么都没学到。

解法：先解包，再挂 LoRA。

```python
for name, mod in list(model.named_modules()):
    inner = getattr(mod, "linear", None)
    if inner is not None and inner.__class__.__name__.startswith("Linear4bit"):
        parts = name.rsplit(".", 1)
        parent = model.get_submodule(parts[0]) if len(parts) == 2 else model
        setattr(parent, parts[-1], inner)
```

挂完必须检查：

```python
print(sum(p.numel() for p in model.parameters() if p.requires_grad))
# 必须 > 0，否则就是又挂错了
```

## 四、保存与续训（躲开优化器死锁）

```python
TrainingArguments(
    save_only_model=True,   # 关键：paged_adamw 保存优化器状态会卡死
    save_steps=3,
    save_total_limit=2,
)
```

- `save_only_model` 是 **TrainingArguments 的字段**，不是 Trainer 的参数（放错地方报 TypeError）
- 每个 checkpoint 只含 adapter（约 170 MB），不含优化器
- 续训：v6 有 checkpoint 就 `--resume`，没有就 `--init-adapter 上一个成品` 热启动

## 五、脚本用法

```bash
set FISH_HOME=D:\your\dir
python trainer/train_qlora_e4b.py ^
  --model D:\models\gemma-4-E4B-it-hf ^
  --data  D:\your\data\train.jsonl ^
  --out   D:\your\out\e4b-lora ^
  --steps 504 --bs 1 --seq 512 --save-steps 3 --duty 0.97
```

参数说明：

| 参数 | 含义 |
|---|---|
| `--seq` | 序列长度，512 是 8 GB 的稳妥值（768 会贴边） |
| `--duty` | GPU 占空比，0.97 实测最快（满载反而被驱动节流拖慢） |
| `--save-steps` | 存盘间隔，3 步一次最安全（蓝屏最多丢 15 分钟） |
| `--init-adapter` | 从成品适配器热启动，优化器重置 |
| `--resume` | 从 checkpoint 续训（需要 trainer_state） |
