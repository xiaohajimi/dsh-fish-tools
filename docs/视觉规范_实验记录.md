# 「实验记录」视觉规范 v1.1

> 定稿：2026-11-20 01:10
> **两个固定画幅，一套设计。** 横屏 4:3，竖屏 3:4（同一个比例，旋转画布）。

---

## 一、画幅（就这两个，不再增加）

| 用途 | 尺寸 | 比例 | 说明 |
|---|---|---|---|
| **横屏**（封面、长视频） | **1440 × 1080** | **4:3** | B 站封面标准；iPad/折叠屏横屏原生 |
| **竖屏**（手机刷的短视频） | **1080 × 1440** | **3:4** | 旋转同一套版式，不重做设计 |

**为什么不是 9:16**：9:16（1.78）在 4:3 平板/折叠上左右大片黑边；
3:4（1.33）在 4:3 设备上只差一点，在手机上则是"上滑时占满宽度"的舒适比例。
**同一比例旋转复用，设计资产只维护一份。**

> 2026 趋势佐证：厂商正从 20:9/21:9 回摆到 16:10、16:9.5，折叠屏内屏普遍 4:3。
> 押"接近方"的比例，比押"细长"更耐久。

## 二、色彩

| 名称 | 值 | 用在哪 |
|---|---|---|
| 纸白 | `#F5F2E9` | 全画布底 |
| 墨黑 | `#22201C` | 主文字 |
| 砖红 | `#A63A2B` | **结论 / 强调数据 / 印章，全图 ≤3 处** |
| 靛蓝 | `#2E4A5F` | 表格线、次级标签 |
| 灰 | `#78726A` | 说明文字 |
| 格线 | `#E7E0CF` | 48px 方格纸（竖屏同样 48px，观感一致） |

**禁止**：渐变、发光、投影、饱和色块、emoji。

---

## 三、字体

| 用途 | 字体 | 理由 |
|---|---|---|
| 标题 / 大数字 / 签名 | **手写体** `CongQCDRMHHJG`（用户提供） | "有人在记录"的质感 |
| 英文标签 / 编号 / 读数 | Cascadia Mono | "机器输出"的对照 |
| 中文正文 | 微软雅黑 / 等线 | 可读性 |

**核心手法**：手写体（人）与等宽体（机器）混排，构成对照。

---

## 四、版式六要素（横竖通用）

```
① 顶部：LAB LOG No.XXX（左） + 时间（右） + 靛蓝细线
② 主读数：手写体大数字（横屏约 190px，竖屏约 210px）
③ 手绘下划线：砖红，分段微抖（不允许直线）
④ 数据条：横屏右侧竖排、竖屏整宽横排；结论条用砖红
⑤ 签名：右下「小哈吉米 记」
⑥ 脚注：遥测数据自动记录 · 仓库地址
```

### 横竖适配规则

| 元素 | 横屏 4:3 | 竖屏 3:4 |
|---|---|---|
| 主数字位置 | 左上 | 上部（占宽 60%） |
| 数据条 | 右侧竖排 | 通栏横排 |
| 表格 | 左下 | 底部 |
| 签名 | 右下 | 右下 |

---

## 五、动作规则（视频）

```
· 数据先行：数字比标题早 120ms 出现
· 留白 ≥40%
· 每 20 秒一次静场 1.2 秒（只有读数跳动）
· 缩放只给数字，不推整屏
· 结尾 3 秒：纸色全屏 + 一行手写 + 仓库地址
```

---

## 六、定位（与主流对照）

| 主流 AI 区 | 我们 |
|---|---|
| 黑底 + 霓虹 + 渐变 | 纸白 + 细线 + 方格 |
| 粗黑体 + 描边 | 硬笔手写体 |
| 感叹号 + 巨大数字 | 编号 + 日期 + 印章 |
| "速度炸裂！" | "占空比 100% 被驱动节流" |

**一句话：不做标题党，做一份可信的实验记录。**
