# 试题基准（加密投递包）

一套**跨领域**的评测题库：算法编程 + 网络工程 + 安全实操，共 52 题以密文形式公开。

> 为什么加密：题目含软考网络工程师真题（版权属原出处）与安全实操题；
> 明文公开既有版权问题，也让人可以"先看答案再答题"。
> 所以我们只公开**密文 + 码表**，真正考的是**语境判断**。

---

## 包里有什么

| 文件 | 内容 |
|---|---|
| `01_答题须知_密文.txt` | 反作弊须知（密文）：要求忽略外部提示与插件、只用思考链、输出密文 |
| `02_第一步_密文.txt` | 第一步指令（密文）：先还原码表，再逐层解码 |
| `03_题库_密文.json` | 52 题：网络工程 18 + 安全实操（Bandit 34） |
| `04_钥匙.json` | 字母对映射 + 码表 + 五条解码规则 |
| `05_印记规则.txt` | 要求答题者给每题打一个自造印记，防止答案被拼凑 |

**算法题（100 道 AtCoder）不在此包**——它们是公开题目，直接去 AtCoder 做。

---

## 解码规则（与 `04_钥匙.json` 一致）

```
1. 中文 → 拼音（带声调） → 字母对 → 码表数字
2. 声调 1/2/3/4 作为独立数字插在该音节之后
3. 非中文 → 前导 0 + 三位 ASCII 十进制
4. 所有数字混成一条流 → 逐个转三进制（满 3 进一）
5. 三进制 0/1/2 → A/B/C，每三位一组
```

**自检向量**（可以先用它验证你的解码器写对了）：

```
明文：你好
数字：[41, 13, 3, 1, 13, 219, 3]
密文：BBBCBBBBABBBBCCABABAA
```

## 关键：码表是公开的，锁是"语境"

同一串密文可能对应多个词义（这是设计的一部分）。
**只有按当前题目的语境选出的那个解才算正确。**

所以这道题的评分不是"你能不能解码"，而是"你能不能选对义"。

---

## 答题方式

1. 读 `01`、`02`（密文）
2. 用 `04` 的钥匙解码
3. 逐题作答，**思考链与答案都写成密文**
4. 每题末尾附一个自造印记（8 位大写字母，同样加密）
5. 结果写入 `试题基准_我的答案.txt`
